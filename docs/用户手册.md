# MaoyeLoc 用户手册

MaoyeLoc 使用 TOML 配置、CSV 观测和 Julia 数据进行局地地震绝对定位、双差重定位及基于外部测量的震级计算。本手册说明命令、配置和结果阅读；物理量定义见[数据约定](数据约定.md)，方程与适用条件见[MaoyeLoc原理](MaoyeLoc原理.md)。

## 开始运行

使用对应系统的可执行包时，完整解压，保留其中的 bin、lib 和 share 等目录。包内附带运行库，无需另装 Julia。源码运行方法见下方命令。

- Windows x64：双击 `install.cmd`，把包根目录的 `myloc.cmd` 命令加入当前用户 PATH，重新打开终端。随包的 `julia.exe` 不加入 PATH；直接运行可用 `.\myloc.cmd` 或 `bin\myloc.exe`。
- Linux x86_64：执行 `sh install.sh`，在 `~/.local/bin/myloc` 建立命令链接。该目录须在 PATH 中；直接运行可用 `./bin/myloc`。需要 glibc 2.34+，实际运行核对平台为 Ubuntu 24.04。
- 安装脚本保留完整程序目录；移动后重新运行脚本。个人配置、观测与结果放在研究目录。

```sh
myloc --version
myloc --template "D:/research/my_case/case.toml"
```

`--template` 生成空白配置，目标目录须已存在。填写实际模型、台站、事件和观测路径后，使用 `myloc --check CASE.toml` 检查，再用 `myloc CASE.toml` 计算。`myloc` 与源码入口调用相同计算，接受同样的 TOML/CSV。批处理命令为 `myloc --batch BATCH.toml`，多个步骤共用一个进程。程序选项在前，Julia 线程参数放在末尾，例如 `myloc CASE.toml --julia-args --threads=4`；配置中还须显式填写对应的 `execution.tasks` 或 `replay_tasks`。

可执行包不含 CairoMakie，绘图及交互 Julia API 使用源码环境。

源码运行使用 **Julia 1.13.2**，计算仅依赖标准库。可选绘图使用 CairoMakie，在同一 Julia 环境中安装和加载，见[绘图说明](#原生结果与绘图)。在项目根目录执行：

```sh
julia --project=. bin/myloc.jl --template "D:/research/my_case/case.toml"
julia --project=. bin/myloc.jl --check "D:/research/my_case/case.toml"
julia --project=. bin/myloc.jl "D:/research/my_case/case.toml"
```

case.toml 可位于任意研究目录，文件路径相对该配置所在目录解析。研究输入和结果保存在项目外。

主入口支持：

| 用法 | 行为 |
| --- | --- |
| `bin/myloc.jl case.toml` | 执行定位和已明确请求的震级、误差与诊断 |
| `--check case.toml` | 读模型、资料和实际参数，不定位、不清理结果 |
| `--show-config case.toml` | 显示实际生效设置，不定位 |
| `--template new_case.toml` | 在已存在的目录中生成待填写模板，拒绝覆盖已有路径；须填写物理模型、时空和观测 |
| `--verbose case.toml` | 显示逐事件/分量进度 |
| `--quiet case.toml` | 仅最终摘要 |
| `--batch batch.toml` | 在同一进程中执行原生 TOML 批处理 |
| `--version` | 程序版本 |
| `--help` | 当前帮助 |

先读结果根目录 run_summary.toml，再看阶段事件和误差。使用 `myloc --diagnostics CASE.toml` 可导出残差、权重和迭代记录。流程 completed 不表示所有事件收敛，--check 成功也不证明射线可达或野外准确度。

以上选项每次选择一种，例如 `julia --project=. bin/myloc.jl --show-config "D:/research/my_case/case.toml"`。`--show-config` 将生效设置写到终端；`--check` 与它都不写入结果。`--template` 生成文件后须先填写，再检查和计算。

源码命令入口为 `bin/myloc.jl`；`bin/maoyeloc.jl` 调用相同的命令处理函数。

构建可执行包时，在项目外的 Julia 环境安装 PackageCompiler，然后在项目根目录执行 `julia --project=BUILD_ENV bin/build_app.jl NEW_BUNDLE_DIRECTORY`。目标目录须尚不存在，Windows 和 Linux 分别在对应系统构建，并需要可用的 C 编译器。预编译使用临时内存输入，计算产物不进入程序包；PackageCompiler 不进入定位计算的运行依赖。

## 原生任务与最小配置

`task` 可为 absolute、relative、absolute_then_relative。第三种先绝对定位，再用该阶段结果作为双差目录；不同阶段的观测、参考和状态分别记录。

```toml
task = "absolute_then_relative"
time_reference_utc = "2026-01-01T00:00:00Z"
coordinates = "Local Cartesian: x east, y north, z down; km"
vertical_reference = "Declared common z=0 plane"
output_directory = "results"
reference_event_ids = ["0001"]

[model]
kind = "constant_velocity_layers"
layer_top_km = [-1.0, 3.0, 8.0]
vp_km_s = [4.8, 6.0, 7.0]
vs_km_s = [2.7, 3.5, 4.0]

[files]
stations = "data/stations.csv"
events = "data/initial_events.csv"
picks = "data/picks.csv"
differentials = "data/differential_times.csv"

[solver]
depth_min_km = 0.0
depth_max_km = 15.0
max_iterations = 50
```

这是结构示例，不是野外速度或参考的推荐。absolute 不需要 differentials；relative 不使用绝对拾取，除非显式 use_absolute_picks 或需要从 picks 配对生成差分。没有初值目录时，绝对任务可按明确 initial_depth_km 及台站中心初始化；研究通常应提供有来源的初值。纯 relative 需要明确初始事件。

接受的顶层键为：task、time_reference_utc、coordinates、vertical_reference、output_directory、files、model、frame、initial_depth_km、solver、absolute_constraints、absolute_weighting、relative、reference_event_ids、pairing、uncertainty、diagnostics、geographic_regions、magnitudes、processing_metadata、depth_reporting、output、execution。未知键明确报错，不静默退为默认值；字段名和时间参考按明确定义解释。

## 输入、单位和逐条身份

长度 km，速度 km/s，时间 s；x 东、y 北、z 下，台站 z=−高程。源、站、层界须共用垂直基准；不是每站下方深度。arrival_s 和 origin_s 相对同一 UTC 参考，跨日不重置。dt_s 是同站同相完整到时 i−j，包含起时差；残差始终观测减预测。

| 原生 CSV | 必需列 | 可选列 |
| --- | --- | --- |
| stations | station_id,x_km,y_km,z_km | 无 |
| events | event_id,x_km,y_km,z_km,origin_s | 无 |
| picks | event_id,station_id,phase,arrival_s,sigma_s | quality_code,observation_id |
| differentials | event_i,event_j,station_id,phase,dt_s,sigma_s,source | original_quality |

表头按名称匹配，列可重排，标准引号内允许逗号、双引号和换行。ID为字符串，保留前导零。sigma须正且有限，不由概率或相关系数推断。phase为P/S，source为CT/CC；来源标签不是独立性或精度声明。

绝对定位允许同站同相多读数，须以不同 observation_id 区分。CSV未给ID时按记录起始物理行生成；内存记录默认 memory_row_N。重排后须保留显式ID，不能重建身份。配对生成CT需要每事件/站/相位恰好一条所选读数，不替用户自动选“最佳”读数。

同事件对/台站/相位/来源的差分不能重复或反向再写一份。CT与CC分别保留；共享拾取的CT相关，CT与其源绝对拾取也相关。完整规则见[数据约定](数据约定.md)。

## Julia 调用与内存计算

```julia
using MaoyeLoc
prepared = prepare_case("path/to/case.toml")
report = check_case(prepared)
settings = effective_config(prepared)
result = run_case(prepared; write_results=false)
# 若需要写出结果，改用 result = run_case(prepared)。
```

prepared 按只读使用，输入或科学配置改变后重新调用 prepare_case。check_case 和 effective_config 也直接接受路径或字典，不运行定位。write_results=false 执行相同科学计算，不创建、清理或写出结果文件，返回的 output_directory 为 nothing；absolute/relative、calculation 和 run_summary 可继续分析。未请求的定位阶段返回 nothing，例如 absolute 任务的 result.relative 为 nothing。

字典入口可逐表给原生内存值，替代对应CSV：

```julia
using MaoyeLoc, TOML
config = TOML.parsefile("path/to/case.toml")
stations = Dict("S01" => (0.0,0.0,0.0), "S02" => (3.0,0.0,0.0))
events = [(event_id="0001",source_km=(1.0,1.0,4.0),origin_s=10.0)]
picks = [(event_id="0001",station_id="S01",phase="P",
          arrival_s=10.8,sigma_s=0.02,observation_id="p01")]
# 以上只说明记录形状，观测数不构成可定位台网。
prepared = prepare_case(config; base_directory="path/to",
                        inputs=(stations=stations,events=events,picks=picks))
```

stations为ID到XYZ字典；events/picks/differentials为NamedTuple向量，顺序及显式身份保留。不猜外部表格列的单位。全部必要内存表已提供时可省略对应文件。

直接数值入口为 locate、locate_catalog、relocate；它们与 case 共用模型和观测定义。完整观测协方差通过 absolute_uncertainty、relative_uncertainty 等误差接口提供，用于传播已有估计器的观测误差，不将定位目标改为广义最小二乘。Julia 帮助 `?locate`、`?relative_uncertainty` 等给出实际签名；case 中未支持的选项通过相应 Julia 接口传入。

## 速度模型与相位定义

`read_model(case_path)` 读model。所有源、站和模型深度使用同一基准，模型顶须覆盖两端，不能静默外延。

| kind | 必需物理字段 |
| --- | --- |
| constant_velocity_layers | layer_top_km、vp_km_s、vs_km_s数组；一层为均匀半空间，末层向下无限 |
| linear_gradient | top_km、vp_at_top_km_s、vs_at_top_km_s、gradient_p_s_inv、gradient_s_s_inv |
| finite_linear_gradient | 上述梯度字段，加bottom_km、vp_halfspace_km_s、vs_halfspace_km_s |
| piecewise_linear_gradient | depth_km速度节点及vp_km_s、vs_km_s数组，节点以下连续、末节点下常速 |
| travel_time_tables | p_table及s_table或vp_vs_ratio二选一，station_plane_km |
| phase_models | p_model子表；s_model或s_scale二选一，后者可加s_offset_s |
| station_models | models子表、default_model、可选station_models和station_delays_s |
| regional_models | models、default_model和有序nodes |
| ray_transform | ray_model及显式源/接收器深度和时间变换 |

常速层允许低速层；连续梯度半空间要求gp≥gs≥0，以保证P始终快于S。有限梯度只要求各相梯度非负、半空间速度不低于层底且端点/半空间P>S，不施加无依据的gp≥gs。分段梯度允许明确条件内的低速带，每相最多一组连续下降段，末速度为该相最大值。详见[原理](MaoyeLoc原理.md)。

### 独立 S 与经验比例

独立S示例：

```toml
[model]
kind = "phase_models"
[model.p_model]
kind = "constant_velocity_layers"
layer_top_km = [-1.0]
vp_km_s = [6.0]
vs_km_s = [3.5]
[model.s_model]
kind = "constant_velocity_layers"
layer_top_km = [-1.0, 5.0]
vp_km_s = [5.8, 6.5]
vs_km_s = [3.2, 3.8]
```

P只使用p_model的P参数，S只使用s_model的S参数，各自正演，不施加P→S比例。

另一明确选择是在phase_models顶层给s_scale=a及可选s_offset_s=b，不给s_model；此时S预测为a*T_P+b，相应源偏导乘a；有P站延迟时该延迟也乘a，不能再给独立S延迟。b为秒的经验截距，不是起时或唯一真实S速度层。a须正，具体适用范围由研究者说明。

### 台站选择、延迟与区域混合

station_models的models存具名完整模型，default_model指定默认ID；station_models子表把完整站ID映射到模型ID。延迟结构例如：

```toml
[model.station_delays_s.local."NET.STA..EHZ"]
P = 0.10
S = -0.04
```

该片段属于已经定义local分支的station_models。正延迟使预测到时变晚，P/S独立；未列为0，不根据Vp/Vs自动缩放。延迟与模型、高程及站身份必须对应，不能重复补偿高程。

regional_models的nodes每项含model_id,x_km,y_km,inner_radius_km,outer_radius_km，models存各分支，default_model用于节点以外。每个区域可包含固定台站选择。区域权随源位置变化；程序混合完整预测并包含F_m*grad(w_m)，不是只混合射线偏导或平均速度。它是多个一维预测的经验加权，不是三维射线。

ray_transform可设source_depth_shift_km、receiver_depth_shift_km、receiver_plane_km、time_scale、time_offset_s。它实际改变射线计算坐标/时间，须有明确物理或经验定义；不能当作显示平移或任意高程修补。

### 原生走时表与生成

```julia
table = TravelTimeTable([0.,1.,2.], [0.,1.,2.],
                        [0.0 0.2 0.4; 0.2 0.3 0.5; 0.4 0.5 0.6];
                        title="explicit table")
write_travel_time_table("table.toml",table)
table = read_travel_time_table("table.toml")
value = evaluate_table(table,0.5,1.2)
```

以上矩阵只演示格式，不代表物理速度模型。time_s行为深度、列为距离，单位秒，Float64直接保存。文件根字段为title、distance_km、depth_km、time_s及可选node_error_s；每轴从0起、严格递增、至少3点，可非均匀。模型中p_table/s_table可为该TOML路径或同形内联表。

每轴取最近内部节点及其两侧共3点，张量积二次Lagrange插值；源偏导由同一多项式求导。超最大节点按最后2点线性外推并标extrapolated；负r/z拒绝。模板切换处若两侧时间/导数不一致则differentiable=false。node_error_s只是调用者声明的节点绝对误差上界，0表示未声明，不是总误差为零；node_error_bounds不包含插值、外推或模型误差。

用于定位的TravelTimeTableModel显式station_plane_km，所有接收器必须位于该面，源表深度为source_z−station_plane_km。独立S表直接使用自身秒值；只有显式vp_vs_ratio才从P表推S。任意站高程应使用直接射线模型，不能随接收点或网格移动物理面。

直接生成：

```julia
model = HomogeneousModel(6.,3.5;top_km=-1.)
table = generate_table(model; distance_km=[0.,1.,2.,4.],
                       depth_km=[0.,1.,2.,5.],phase="S",
                       station_plane_km=-0.3,title="S first arrivals")
```

CLI为：

```sh
julia --project=. bin/generate_travel_time_table.jl model_and_grid.toml output_table.toml
```

输入含常规model定义和table表，后者含distance_km、depth_km、phase、station_plane_km、title。生成接受五类一维射线模型，物理模型由model显式定义。网格只控制取样，不改变源面或接收面。表分辨率须在研究范围与直接正演核对。

### 给定发射角的射线与几何密度

首波求解之外，可对分段连续梯度模型调用：

```julia
ray = trace_ray(model, 10.0, 120.0; phase="P")
density = ray_geometric_density(model, 10.0, 120.0; phase="P")
```

model为PiecewiseGradientModel，源深度采用共同计算z（km）；launch_angle_deg从**向上竖直**计，0上行、90水平、180下行，与从向下竖直计的源角不要混用。分别使用实际P/S速度剖面。返回到顶面、进入半空间不返回、水平传播、两次埋藏转向波导等状态；只在到顶面时给距离/时间，转向信息仅描述真实转向，不伪造为半空间入口。

ray_geometric_density计算sin(phi)/(r*abs(dr/dphi))，单位km⁻²，其中导数按弧度；上行竖直用解析极限，其他角在同分支上差分。它是表面环面积的几何密度，不是完整弹性波振幅或衰减计算；分支切换、不能返回、源在顶面或未解焦散时返回nothing。按深度或角度数组逐次调用可生成射线曲线。

## 求解、参考与资料选择

共同solver表默认：

| 参数 | 默认与含义 |
| --- | --- |
| depth_min_km / depth_max_km | 模型顶 / Inf，共同z坐标下边界 |
| max_iterations | 50，硬迭代上限 |
| location_tolerance_km | 1e−6，未阻尼空间步判据 |
| time_tolerance_s | 1e−7，未阻尼起时步判据 |

初值不自动移动到边界。绝对定位可令深度上下界相等，或用下述逐事件 fixed_depth 约束固定输入深度。相对定位按每个事件的四个改正量求解，不接受把深度上下界设成同一个值来固定深度。

### 绝对定位

绝对定位采用经验行因子、位置与发震时刻的 SVD 改正、步长控制和残差/步长停止规则，方法参考 HYPOINVERSE。`solver.method` 省略或写 `hypoinverse`。`sigma_s` 表示测量标准差，不作为定位方程的行因子。

```toml
[solver]
method = "hypoinverse"
```

默认质量行因子为 [1,0.75,0.5,0.25]，S 行因子 0.5；距离权从第 4 次迭代开始，半径下限 50 km、内外因子 1/3；残差权从第 4 次开始，下限 0.16 s、内外因子 1.5/3、两遍更新。初始距离权从第 100 次开始，下限 50 km、内外因子 3/6。谱/步控制为 eigtol=0.012、singular_value_shift=0.006、dxfix=7 km、dzmax=30 km、dzair=0.5、damp=0.9、late_damping_factor=0.5、dxmax=50 km、rback=0.02 s、bacfac=0.6、d2far=250 km；默认停止参数为 dquit=0.04 km、drqt=0.001 s、legacy_iteration_limit=20；达到该迭代参数后仍需满足相应 RMS 条件，另受 max_iterations 硬上限约束。参数可显式覆盖，实际生效值写入 calculation.toml。

每轮确定经验权后，程序在固定该轮权重的条件下检查候选步，必要时缩短步长；更新后重新加权导致 RMS 增大时，还可按 rback_s 和 bacfac 回退。动态重加权的定义及其与固定权最小二乘的关系见[原理说明](MaoyeLoc原理.md#测量标准差与方程行因子)。

固定深度或位置属于约束，传播模型决定走时，误差计算分析所求结果。这些都不另算一种定位方法。

逐事件可配置：

```toml
[absolute_constraints."0001"]
mode = "fixed_depth"
source = "independent depth constraint"
```

mode为free、fixed_depth、fixed_position或fixed_all，固定值来自该事件输入坐标/起时。它只作用于绝对阶段；双差使用自己的reference_event_ids和边界。

权重就是这条路径的经验行因子：质量、台站、S 因子以及距离/残差渐变。quality_weights 四值默认 [1,.75,.5,.25]，quality_code≥4 为零。每条到时必须带 quality_code，或写明 default_quality（0–9 的整数）。省略该列不是质量 0，也不由 sigma_s 换算。sigma_s 仍要填写，但它不是方程权。station_time_weights 按完整站 ID，s_weight 作用 S 行，默认 0.5。表内显式键覆盖预设中的同名项。distance、initial_distance、residual、event_rules 分别定义起始迭代、尺度、渐变和少资料处理。

显式谱/步控制可选eigtol、singular_value_shift、dxfix_km、dzmax_km、dzair、damp、late_damping_factor、dxmax_km、rback_s、bacfac、d2far_km、station_site_ids、stopping_rule、dquit_km、drqt_s、stop_start_iteration、legacy_iteration_limit。这些选择会进入完整XYZ/O谱路径，详细定义见locate帮助及[原理](MaoyeLoc原理.md)：

- eigtol为物理时空列及共同尺度下的绝对奇异值阈值，非相对百分比；保留方向使用1/(s+singular_value_shift)作迭代乘数。
- damp/late_damping_factor缩放迭代步，dzmax_km限制垂向，dxmax_km限制空间步，dzair控制接近模型顶的步；不是观测误差或位置先验。
- stopping_rule="legacy"按显式RMS/受控步规则停止，状态stopped_by_legacy_rule不代表严格未阻尼步收敛。legacy_iteration_limit只适用于该规则，0表示固定XYZ只解起时，max_iterations仍是硬上限。
- stopping_rule="step"按保留奇异方向内的未阻尼改正量检查 location_tolerance_km 和 time_tolerance_s，此时不填写 legacy_iteration_limit。Julia 接口也可显式传入 legacy_iteration_limit=nothing。该选择不改变行权、谱截断或步长控制；默认仍为 legacy。
- rback_s和bacfac控制相对历史最小RMS的回退；d2far_km限制第二近不同物理站的水平距离，不是震源距离剪裁。

偏大残差通过残差权降低方程因子。

### CT 配对与双差

已有差分直接由files.differentials提供。若从picks生成CT，需明确：

```toml
[pairing]
max_separation_km = 2.0
max_separation_ratio = 0.1
min_common_stations = 4
```

这些是示意阈值。pair_catalog要求事件三维间距及其与较近源台距之比均满足，且有足够不同坐标的站点；共同路径几何只提供条件，不证明三维误差必然抵消。catalog_differences用于明确给定事件对；CT由独立拾取sigma平方和传播，但不同CT共享误差仍相关。

`pair_neighbors`另保留按近邻、强链与观测预算选择CT的算法，可直接用Julia返回的observations交给relocate。它与pair_catalog的共同路径比值筛选不同，不自动替换默认配对：

```julia
selected = pair_neighbors(events, stations, selected_picks; frame,
    min_quality=0.5, max_station_distance_km=100.0,
    max_separation_km=2.0, max_neighbors=10,
    min_links=8, min_observations=8, max_observations=50)
```

这是结构示例，阈值不是通用研究推荐。selected_picks为Julia读数记录，除到时/sigma/身份外必须给非负无量纲pair_quality，可给important布尔项；不能把质量码、负号或sigma猜成配对权。重要性只跳过min_quality并改变预算排序/数量，不绕过距离与粗差条件。粗筛为`abs((arrival_i-origin_i)-(arrival_j-origin_j)) ≤ separation/v + padding`，显式参数coarse_velocity_km_s默认(P=4.,S=2.3)、coarse_padding_s默认0.5s，这是经验筛选条件。所有所选CT仍为完整到时i−j，sigma按独立拾取传播，平均pair_quality仅供显式经验DD权使用。每对/读数/事件的选择与未用原因均返回。

相对定位只有一条路径，沿用 HypoDD 的思路：差分按类别、事件间距和残差分阶段改权，四个改正量做列缩放后再加阻尼。小系统用这个阻尼问题的密集 SVD，大系统用 LSQR。不自动固定某个事件。绝对位置靠阻尼把改正拉向零，也就是留在目录初值附近。显式 `reference_event_ids` 仍可按事件钉住，那是额外约束，不是默认基准。默认第一阶段 P、S 类别因子都是 1。后两个阶段目录 S 为 0.6，第三阶段互相关 S 也为 0.6。不写 `relative.weighting.stages` 时用这组默认；写了就整表替换，表内省略的类别因子按 1。阶段次数、距离和残差门槛、阻尼也可在该表里改。

```toml
[relative]
use_absolute_picks = true
absolute_failure_policy = "stop"
initialization = "catalog"
```

`linear_solver` 选择同一阻尼问题的算法：auto 对较小矩阵用密集 SVD、较大用 LSQR，也可写 dense 或 lsqr。lsqr_rtol 默认 1e−6，lsqr_max_iterations=0 使用内部规模规则，lsqr_condition_limit 默认 1e12。lsqr_rtol 是线性残差的相对阈值，不是以km表示的位置误差；弱约束事件的线性数值差可经后续重加权和退出规则放大，需要更严格线性解时可显式设定更小值。未收敛状态须结合结果阅读。

use_absolute_picks 把绝对到时加入双差，绝对行默认因子为 1。ABS→DD 绝对阶段失败默认 stop。initialization=centroid 将每群空间初值移到等权中心，但保留各事件起时和完整差分。initialization_coordinates 可选 cartesian/geographic，后者需显式 frame。

显式 `absolute_failure_policy="exclude"` 会同步筛除失败事件涉及的差分、联合绝对拾取及对应逐行权数组。经验 `absolute_row_weights` 按排除前的全部联合绝对拾取填写，程序使用同一保留索引筛选。最终残差和逐观测诊断中的 `input_row` 保留各自原始输入列表的一基记录序号，不是包含表头的 CSV 物理行号；被排除记录也保留原序号，标为未进入 DD、实际方程行因子为 0。

relative.selection的idat=1/2/3分别选择CC/CT/二者，ipha=1/2/3分别选择P/S/二者；event_ids选择原字符串ID。obscc与obsct的有效和给出建立强事件对所需的观测数阈值（仅使用被选择的来源）。该和为正时，强链确定群，群内再读入弱链。该和为0时，保留下来的差分图按连通分量分别求解，分量不自动固定参考事件。cluster_id=0处理全部所选群，正值选择特定群。max_station_distance_km是基于明确frame的群中心至台站距离上限，默认Inf；初筛与分群后的中心/重新读入规则按群处理，不是逐事件震源距裁剪。

relative.selection可显式设置资料类别、相位、事件、群、台站距离和强链阈值；relative.weighting mode="empirical"使用分类质量因子及有序stages，每阶段iterations按成功全群更新计数。每阶段可给wtccp/wtccs/wtctp/wtcts（CC/CT的P/S类别行因子）、wrcc/wrct（残差截止参数）、wdcc_km/wdct_km（事件间距截止，km）和damp（列缩放空间中的阻尼）。负original_quality在定位权层明确排除，不当作配对优先标记。更详细字段见relocate帮助和源函数定义。

默认airquake_policy=bounds按深度边界处理。显式exclude_repeat在完整试步源深度严格越过airquake_depth_km（默认0）时拒绝整个群更新，退出触发事件及相关观测，再做同次成功迭代；不重置群中心、重新分群或静默换参考。负z可以有合法物理含义，不能默认开启此规则。

## 误差、诊断和置信范围

默认未请求的误差保持not_estimated。条件误差固定模型、站、相位、分支、权和参考，不包括它们的真实误差。先看status/reason再看数字；固定参考、固定深度或不可辨方向不报告假零。

目录 CT 若与联合绝对到时满足 dt = arrival_i − arrival_j（同一台站、同一震相，容差 1e-9 s，且两侧各只有唯一匹配），这些行与对应到时共用测量误差。此时 assume_independent_relative_observations=true 会报错，避免把相关观测当成独立后把形式误差算小。未声明独立、也未另行给出协方差时，条件协方差按这个线性关系构成，定位仍用原来的对角行权，震源坐标不变。CC，以及到时差对不上的 CT，保持各自的 sigma_s。用户给出的 observation covariance 优先于这一自动关系。

独立sigma假设下的示例：

```toml
[uncertainty]
assume_independent_picks = true
ellipsoid_probability = 0.95
relative_events = "all"
relative_pairs = [["0001","0002"]]
relative_confidence_probability = 0.95
assume_independent_relative_observations = true
relative_covariance_method = "analytic"

[uncertainty.formal]
rderr_s = 0.15
ercof = 1.0
noise_model = "weighted_rows"

[diagnostics]
absolute = true
quality_covariance_source = "formal"
```

ID必须存在。上述独立性仅在资料构造支持时使用；共享拾取 CT 或 CT 与源绝对拾取不能直接声明为独立。完整观测协方差通过直接 Julia 误差接口提供，顺序为全部差分后全部绝对拾取；半正定可用。它会先被检查，不把阻尼双差改写成另一套加权最小二乘。

`absolute_uncertainty` 对经验行因子定位返回未估计。`absolute_formal_uncertainty` 冻结保存的方程权，用 q=rderr_s²+ercof*RMS² 作工作噪声。`weighted_rows` 按该行权基准假设加权行方差 q，`arrival_rows` 假设原到时方差 q，两者不同。相对定位的解析协方差对列缩放阻尼返回未估计；观测误差穿过完整重定位时用 `algorithm_replay`。这些产品不是原版弱方向谱，也不是完整非线性算法的误差。

列缩放阻尼的解析接口返回未估计。需要把观测误差传过完整重定位时改为：

```toml
[uncertainty]
relative_events = ["0002"]
relative_covariance_method = "algorithm_replay"
assume_independent_relative_observations = true
relative_algorithm_method = "auto"
relative_algorithm_noise_samples = 128
relative_algorithm_seed = 0
relative_replay_step = 0.02
```

该片段替换相同uncertainty表，不与前例重复声明。它完整重算每个观测扰动，auto在≤128个非零噪声方向时exact，否则randomized；分别报告导数数值核对与Monte Carlo抽样误差。初始目录固定，模型/初值/参考真值误差和有限迭代偏差不包含；不是bootstrap/jackknife。扰动改变离散路径或遇到非光滑、边界时可返回不可估。

逐轴边际正态半宽与联合空间椭球不同，后者按实际维数χ²尺度。3D95%约2.79548倍单位Mahalanobis半径，不能以2.4宣称95%。诊断表的信息、几何、条件数或质量码均不独立等于真实准确度。

## 震级：输入测量、校准与汇总

震级从外部已经测得的振幅、周期、F−P尾波持续时间计算，不测量波形。普通case在绝对阶段目录上计算；ABS→DD不自动按最终DD位置重算。任意已有目录可显式调用magnitude_preparation(events,stations,settings;time_reference_utc,model,frame)。

magnitudes.channels以完整站/通道ID连接，measurements逐条提供实际测量。一条同时含coda和振幅的测量写一条，避免因P/S重复计入同一实际测量：

```toml
[magnitudes.channels."S01"]
instrument_type = 3
component = "EHZ"
calibration_factor = 3.95
default_period_s = 0.2
coda_correction_mag = 0.0
amplitude_correction_mag = 0.0
coda_weight = 10
amplitude_weight = 10
coda_gain_enabled = true

[[magnitudes.measurements]]
event_id = "0001"
station_id = "S01"
duration_s = 120.0
coda_quality_code = 0
amplitude = 100.0
amplitude_units = 2
amplitude_type = 0
period_s = 0.25
amplitude_quality_code = 0

[magnitudes.selection]
```

仅演示结构，仪器、增益和经验关系须核实。缺测省略字段，TOML不写null或“missing”，0不是缺失。measurement有duration_s启用coda，有amplitude启用振幅；显式空coda_magnitudes/amplitude_magnitudes表也可启用对应计算。存在selection/aggregation/preferred/display/external等时再汇总事件槽。

### 仪器与历史

instrument_type为原关系的0:7：0 Wood–Anderson，2 Sprengnether，1/3:7为各自固定电机常数的速度仪器约定；不是任意仪器响应反卷积。台站增益从calibration_factor、attenuation_db、digital_system_factor_uv_per_count三者至多一种明确给出。CAL无量纲，数字系统F为μV/真实count；输入按百count编码不能把F再乘100。具体系数见magnitude_calibration帮助及[实现](../src/magnitude_calibration.jl)。

calibration_history/attenuation_history数组按完整station_id精确匹配，各行含value及可选expires_utc。UTC小时半开区间，到期时使用下一行；首行向过去延伸，末行省略到期向未来延伸。同通道到期递增，不要求事件按时序执行。有匹配但已过期的历史不回退静态值；非零phase_cal显式覆盖，0/省略不覆盖。CAL=0可允许零coda增益项，但不能假造有效振幅校准；正CAL时原始coda增益项为−log10(CAL/3.95)。

duration_history/amplitude_history保存站改正随时间的记录，component_coda/component_amplitude保存组件改正。静态coda_correction_mag、amplitude_correction_mag及记录中的value都直接表示震级增量mag；例如value=0.15表示加0.15mag。研究者应依据校准确定实际改正值。

通道coda_weight/amplitude_weight显式给0:10事件汇总站权，默认10；coda_gain_enabled明确是否使用尾波增益改正，默认true。匹配历史可用event_weight覆盖对应通道站权，否则继承通道值；duration_history还可用gain_enabled覆盖通道尾波增益开关，否则继承。历史本身不把站权重置为10。权为0仍保留站震级，只退出事件汇总；禁用增益只关闭相应增益项，不删测量。

```toml
[[magnitudes.duration_history]]
station_id = "S01"
value = 0.15
event_weight = 0.0
gain_enabled = false
expires_utc = "2026-07-01T00:00:00Z"
```

该示例在对应时段使用+0.15mag改正、站汇总权0并禁用尾波增益；不是一般推荐。记录过期时改正未知、事件权0，不回退静态值。use_unlisted_coda/use_unlisted_amplitude只控制未列入改正记录的通道能否进入事件汇总，组件改正按完整代码累计。instrument_type覆盖是通道静态选择，须先于校准；定位权不影响站震级计算。

### 尾波与振幅关系

Md1/Md2分别对持续时间D使用分段的常数、log10(D)、D、深度、震中距、增益及站/组件项。默认折点210s，恰等于时取较长持续时间分支upper；两段默认常数−5.2/−0.905，log系数3.89/2.026，深度0.013mag/km，距离0.0037mag/km，线性和增益系数0。md1/md2下可分别给duration_break_s、gain_coefficient和lower/upper系数表。

Mt用tau=模型P几何走时+D，排除起时、站延迟和相位截距，tau须>0.5s；默认−1.03+2.10log10(tau)+0.00268tau，再加所选增益、深度和改正项。P模型不可用可使Mt不可估，不应连带删去仍可计算的Md。完整字段和附加距离/深度项见coda_magnitudes帮助。

| amplitude_units | 实际测量约定 |
| --- | --- |
| 0 | 峰峰mm |
| 1 | 单峰mm，乘2为峰峰 |
| 2 | Menlo/Earthworm峰峰count，0.04883mm/count |
| 3 | HVO峰峰count，0.012207mm/count |
| 4 | Menlo百count编码，4.883mm/输入单位 |

amplitude_type为0按仪器选择ML/MX，1为已表达成Wood–Anderson记录的ML，2为速度MX，3加速度不计算，4显式不计算。周期正值优先，缺失/非正用通道default_period_s；非数值/非有限仍无效。允许周期0.02–6.3s不代表经验响应在整个范围均有物理保证：共有L4C/WA响应近似主要3–10Hz，Sprengnether拟合0.1–1.9s，输出范围旗标需保留。

amplitude_magnitudes.distance_relation为0省略距离项，1 Eaton，2 Bakun/Joyner，3 Richter近似，4 Nordquist表线性插值，5 Richter离散表，6 CISN/Uhrhammer。1/2/3/6的斜距为hypot(震中距,计算z)+0.01km；4/5用震中距。Nordquist到2224km，CISN要求0.1<斜距≤500km；表与经验系数的范围不应外推为任意地区标定。具体公式和分项见amplitude_distance_correction帮助及[实现](../src/amplitude_magnitudes.jl)。

### 事件选择、权与优选

selection分别配置coda1/coda2、amplitude1/amplitude2四套测量集合；不是统计独立声明。coda槽可选md1/mt/md2，组件all/none/完整列表；振幅槽按component或显式instrument模式选择，再独立筛ml/mx。fmag2_region使用实际经纬度框，东经为正、不跨日期线，需要frame。站值保留，即使未进入事件汇总。

震级观测权由quality_code与独立0:10站权决定：质量0:3给NINT(2.5*(4−quality)*station_weight)，4:9给0。定位sigma和定位重加权不参与。aggregation默认native保留完整Float64；median最小化加权绝对偏差，MAD只描述散布；mean配套平方权RMS，也不作置信区间。显式quantization="legacy_centimag"使用HYPOINVERSE的MEDWT中点插值及0.01mag舍入，是另一数值定义，不能混为native中位数。

preferred从有序规则在coda1、amplitude1、external、amplitude2、coda2中选择，display独立准备显示列，不改源震级。有效零和负震级保留；未算、未选和无权均有独立原因。完整可选字段见magnitude_selection、event_magnitudes、preferred_magnitude、magnitude_display帮助及对应源码。

## 地理输出、深度报告与处理元数据

原生输入为局部km；可显式声明frame来输出地理位置：

```toml
[frame]
geographic_crs = "EPSG:4326"
horizontal_projection = "WGS84_local_orthographic"
latitude_deg = 30.0
longitude_deg = 104.0
vertical_datum = "Declared common z=0 plane"
```

vertical_datum须与顶层vertical_reference一致。这是WGS84局地正射投影；高程基准单独明确，不估大地水准面起伏。

depth_reporting需明确coordinate_datum=model/geoid、model_datum=nearest5/geoid、report_datum=model/geoid，可给model_zero_km、station_elevations_km、station_site_ids、event_stations、regional_model_datums及station_selection。nearest5/nearby5选站规则见[数据约定](数据约定.md)。报告只追加深度字段，不移动源、台站、层界或改条件协方差；未知H留空，真实0有效。若质量分类使用报告深度，报告规则也可能改变质量码。

processing_metadata为原生表或显式TOML路径，逐读数按event_id/observation_id连接。没有读数ID时仅允许唯一站相匹配，不猜重复记录。first_motion明确给出，不从phase_remark第3字符推断；metadata_accepted和metadata_exclusion_reason说明元数据是否采用。元数据、初动/备注及地区名称不替代到时测量，也不形成新的定位约束。

`processing_metadata.equation_weight` 与定位残差表一致，使用保存的经验行因子。`weighted_data_source_counts` 按对应报告行因子≥0.1计数，`primary_weighted_data_source` 据此选择；该计数是报告约定，不是独立信息量。初动标签计数独立于最终行因子。

geographic_regions使用随包通用地区多边形或显式原生资料；地区命名不是速度模型反演。事件几何统计来自实际原生到时读数，不把空元数据记录当台站约束。

## 原生结果与绘图

默认在absolute/、relative/保存简明events.csv，含事件ID、位置、起时、状态、使用资料数和误差状态。配置地理参考时增加geographic.csv。已请求的误差保存相应误差、协方差及其定义，未估计的量留空。根目录calculation.toml保存坐标、单位、输入及生效参数，run_summary.toml保存阶段/事件计数、状态和耗时。

详细诊断通过命令行 `myloc --diagnostics CASE.toml` 或以下配置开启：

```toml
[output]
diagnostics = true
detail = "full"
```

诊断开启后，阶段目录增加以下文件。`detail="core"` 省略逐次历史及谱方向，`detail="full"` 导出完整诊断。

| 文件类别 | 应读内容 |
| --- | --- |
| events.csv | 完整字符串ID、计算位置/起时、状态、约束、资料和误差状态 |
| residuals.csv | 原观测、预测、观测减预测、实际权、使用与原因 |
| components.csv / absolute_residuals.csv | DD连通群、参考/求解器及联合绝对约束残差 |
| iterations及方向/尺度表 | 本次迭代、实际步、权、谱/LSQR诊断与选择 |
| formal_errors/covariance、ellipsoid/axes | 已请求并可估的形式误差及置信含义 |
| event/pair_uncertainty与条件协方差 | 已请求事件或事件对的误差、不可估原因及假设 |
| event/station/component统计与diagnostics | 残差、几何、资料计数及未用原因 |
| magnitude相关CSV/TOML | 校准、站值、事件选择/汇总、优选及显示 |
| geographic / datum_stations | 显式frame/报告规则下的附加坐标和选站记录 |

误差计算由uncertainty设置请求，输出开关沿用其估计器及假设。默认运行省去逐观测几何和详细统计的附加分析及文件导出，求解所用观测、权重、阶段及误差计算保持同一条路径。诊断模式具体省略文件见output_detail.toml。CSV中缺失量留空，结合status/reason阅读，真实零和有效负值保留。read_location_results读取两种模式的原生目录，保存值保留完整精度。

Julia 返回的双差分量 `weight_trace` 支持按行索引和遍历，完整保留每次尝试的观测身份、权重、残差和退出原因。共同的身份与阶段信息共享存储；如需独立的逐行数组，可调用 `collect(component.weight_trace)`，此时会增加内存占用。

再次运行同一输出目录时，程序先清理本次请求阶段中已知名称的旧结果，再写入本次结果；未请求阶段的旧目录可能仍存在。请按本次 run_summary.toml 的 executed 和 completed_stages 判断实际执行的阶段，需要保留多次计算时使用不同 output_directory。`--check` 的 previous_stage_directories 会列出未请求但已存在的阶段目录。

绘图使用 CairoMakie。在准备绘图的 Julia 环境中安装一次：

```julia
using Pkg
Pkg.add("CairoMakie")
```

每次绘图前加载 CairoMakie，即可直接使用定位结果及台站：

```julia
using MaoyeLoc, CairoMakie
# 接上文 prepared 和 result；选择本次实际执行的定位阶段。
locations = result.relative === nothing ? result.absolute : result.relative
plot_location_results(locations, prepared.stations;
    output_directory="figures", frame=prepared.frame,
    vertical_datum=prepared.config["vertical_reference"])
# prepare_location_plot(...) 只准备 CSV/TOML，不需要安装 CairoMakie。
```

文件入口可将结果 events.csv 和台站表直接给为两个 CSV 路径。原有三个参数入口（初始目录、结果目录、台站）也保留，初始目录仅作为对照数据保存；默认图只画提供的结果目录。

默认输出一张组合图 locations.png/pdf：左上为事件水平分布及全部提供台站，右上为深度—南北坐标剖面，左下为东西坐标—深度剖面，三个面板中的事件均按同一深度色标着色。右下为累计事件数—时间图，其宽度与上方剖面对齐，高度与左侧剖面对齐；四个子图采用统一的标题、轴名与刻度字体设置。深度色标横置于台站和事件状态图例所在的同一行，标题在左端，刻度在下方。提供 frame 时，水平坐标采用相应经纬度；否则使用原有东/北 km。计算 z 直接作为深度，深度向下递增的面板保持该方向，不另作基准转换。

图中保留全部提供事件，并以符号区分实际状态；N 是传入结果目录的事件记录数。累计图按已有 origin_s 排序，横轴为距最早已知起时的时间，自动以 s、min、h 或 d 标注；缺少起时的记录不补零，子图标题的 n 为有效起时数/目录记录数。图件不自动拟合震级频度关系或开展目录筛选。RMS 等诊断仍可从计算结果读取，默认不出图。

局部 km 水平图保持空间比例，经纬度图按 frame 的参考纬度调整经纬度显示比例，作为局地范围的近似。两个深度剖面的显示比例由面板布局决定，按实际坐标刻度阅读；深度基准保存在 plot.toml 中。图中只使用图名、子图名、轴名、刻度、图例和必要的图内标注，不添加底部或子图下方的说明小字。保存的绘图 CSV 保留原坐标、秒和完整精度。prepare_location_plot 的 section_* 参数仍可用于导出指定方位的沿线/横向坐标和宽度标记，默认组合图只使用正交投影、不按这些标记筛除事件。科学图件禁止 viridis。

已有 prepare_location_plot 保存的绘图目录时，可调用 `plot_location_results("figures")`，或在装有 CairoMakie 的项目环境中运行：

```sh
julia --project=. bin/plot_locations.jl figures
```

该命令读取目录中的 initial.csv、relocated.csv、stations.csv 和 plot.toml 重新出图，不重新定位。

## 报告、状态、批处理与人工复核

write_location_report(path,absolute_result,model,stations;time_reference_utc,...)输出可读报告及全精度TOML伴随。detail=0:4依次增加读数/震级、迭代/权、谱/协方差/误差、逐迭代预测；附加内容来自实际计算，不补造未算产品。write_magnitude_details独立导出震级分项。直接调用示例：

```julia
write_location_report("report.txt",result.absolute,prepared.model,prepared.stations;
    time_reference_utc=prepared.reference,detail=3)
```

`save_physical_state(path,config_path;metadata=nothing)` 保存配置及部分配套资料，文件格式名为 MaoyeLoc physical state 2；`load_physical_state(path;output_directory=...)` 恢复原生配置。站表和 P/S 走时表文本嵌入，事件、拾取和差分保留绝对路径引用；自定义 metadata 可保留矩阵形状及 nothing/missing/Symbol。这里的“状态”指配置资料，不是地震波场、已定位目录或迭代检查点；恢复时原始观测引用仍须可用。

`run_batch("batch.toml")` 或命令 `julia --project=. bin/batch.jl batch.toml` 执行有序 steps。顶层 case 或 configuration 提供原生配置，output_directory 提供批目录。最小结构：

```toml
case = "case.toml"
output_directory = "batch_results"
[[steps]]
action = "query"
keys = ["model.vp_km_s", "absolute_weighting.mode"]
[[steps]]
action = "run"
output_directory = "run_01"
```

action仅set（嵌套values，可用remove点分路径）、case(path)、query(keys可选)、run(output_directory可选)、review(path)、command(argv及可选directory)、save_state(path)、load_state(path)、include(path)、repeat(count,steps)、message(text)、return、stop。include按自身文件解析路径并共享当前设置；repeat保留有序设置变化。外部命令通过argv逐项给出。calculation_defaults()只给数值默认值，物理模型、sigma和时区须显式填写。要保留多次结果应分开输出目录。

`review_catalog(case_path,steps;output_directory=...)` 或 `run_catalog_review("review.toml")` 按显式事件与逐条读数复核；命令入口为 `julia --project=. bin/review_catalog.jl review.toml`。顶层为 case/steps/output_directory。每 step 含 event_id 及 action=recalculate/accept/skip/delete；edits 数组必须给 observation_id，可改 arrival_s、sigma_s、quality_code（仅 empirical）、phase_remark、first_motion、remark。trial 位置、起时及 constraint 模式显式提供；measurement_edits 用于明确震级测量修改。复核保存工作配置、修改值、尝试和决定，不把 accept 当科学真值，也不静默影响其他读数。工作拾取里本来没有 `quality_code` 时，保存的 picks.csv 也不写这一列，不会补成 0；同一文件里有的读数有质量码、有的没有，则拒绝保存。review.toml 结构示例如下，须换成实际已有的事件和读数 ID：

```toml
case = "case.toml"
output_directory = "review_results"

[[steps]]
event_id = "0001"
action = "recalculate"
edits = [{observation_id = "p01", sigma_s = 0.02}]

[[steps]]
event_id = "0001"
action = "accept"
```

accept 要求当前修改已有重新计算的结果；skip 保留输入及已有尝试，delete 从保存的工作目录中移除事件而不删除原始资料。完整字段见 Julia 帮助 `?review_catalog`。

## 并行、复现和限制

```toml
[execution]
tasks = 2
replay_tasks = 1
[output]
diagnostics = false
```

以 `julia --project=. --threads=N bin/myloc.jl case.toml` 启动才有相应线程。tasks 并发独立绝对定位事件或完整双差连通分量，并按原序归并，不拆同一群；replay_tasks 为同一噪声方向 ±h、±h/2 四次完整重算的请求并发上限，实际最多为 min(replay_tasks,4,Threads.nthreads())。后者用于显式请求的阻尼双差算法误差传播。两者不可同时大于1，程序不自动改 BLAS 线程。随机传播保存实际方法、种子和样本数；并行保持相同观测、随机方向和选择规则。耗时包含首次编译成本。

并发任务在工作线程空闲时继续分配，避免少数耗时事件或分量阻塞同一线程上的其余任务。独立事件较多且每次矩阵较小时，可在启动 Julia 前设置 OPENBLAS_NUM_THREADS=1，减少多任务与 BLAS 内部线程争用；大矩阵求解仍应按实际规模比较，线程越多不保证越快。

复现至少保留研究目录的输入、明确配置、程序版本及实际生效设置，尤其是模型、垂直基准、UTC 参考、差分定义、权与参考条件。科学判断应结合独立公式或参考计算，野外准确度还需考虑模型与观测条件。误差产品的适用范围见[原理说明](MaoyeLoc原理.md#不确定性及置信范围)。
