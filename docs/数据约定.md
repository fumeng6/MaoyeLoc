# 数据约定

本文件定义 MaoyeLoc TOML、CSV 和 Julia 内存记录的物理含义。文件用法见[用户手册](用户手册.md)，公式和适用限制见[MaoyeLoc原理](MaoyeLoc原理.md)。输入须明确字段名、单位、时区和差分参考状态，程序不猜测这些定义。

## 单位、坐标与垂直基准

| 量 | 单位与方向 |
| --- | --- |
| 长度、坐标和深度 | km |
| P/S 速度 | km/s |
| 时间、走时、到时误差 | s |
| 速度随深度梯度 | s⁻¹ |
| 局部坐标 | x 东、y 北、z 下 |
| 高程 h | 向上为正，站坐标 z=−h；二者须共用基准 |
| 源走时偏导 | `(dT/dx_source,dT/dy_source,dT/dz_source)`，s/km |

计算默认 Float64。源、台站和速度模型层界必须使用同一坐标系及垂直基准；负 z 可以有效，不能自动截为零。模型顶面须覆盖两端，不静默延拓。地理资料应记录原始坐标系、参考位置和高程基准；椭球高、海拔和台站下方深度不能互换。原生 `coordinates`、`vertical_reference` 是明确的说明，不会自动投影或改变单位。

`LocalFrame` 提供显式地理与局部坐标换算，适用于局地范围。其WGS84椭球和明确参考点须与外部资料一致；不能把它当作任意投影或大地水准面模型。

## 时间和预测

一次计算选定共同的 UTC 参考 `time_reference_utc`，以 Z 结尾。`arrival_s` 和 `origin_s` 都是相对该参考的秒，可跨日且不在零点重置。不能混用 Unix 大秒数、相对秒或不同参考，也不能把北京时间标签当成 UTC。当前普通配置使用 Julia DateTime 参考，应使用整秒或毫秒精度的共同参考；打印更多小数不增加实际准确度。

记事件发震时刻为 O，所选模型的完整相位预测项为 F：

```text
arrival_pred(i,k,p) = O_i + F(source_i, station_k, phase_p)
dt_pred(i,j,k,p) = O_i - O_j + F_i - F_j
residual = observed - predicted
```

F 包含实际适用的射线/表走时、相位关系、已知台站延迟及区域混合。起时只加一次。正台站延迟表示预测到时变晚；延迟不是观测预扣项，不应再次补偿已由台站坐标体现的高程效应。

差分 `dt_s` 固定为**同站同相完整到时 i−j**。交换事件顺序必须变号；相对参考起时的差、波形 lag 或仅传播走时差应先显式转换，不能直接当作同一量。

## 字符串身份与观测

`event_id`、`station_id` 是非空字符串，保留前导零；不静默重编号。绝对拾取允许同站同相多条读数，以 `(event_id,observation_id)` 区分，不能通过字典覆盖或去重消失。CSV 未给 observation_id 时按记录起始物理行生成；内存记录未给时按输入原序生成 `memory_row_N`。重排/筛选后需要保持身份时，应保存原有显式 ID。

相位为 `P` 或 `S`。差分 `source` 为 `CT` 或 `CC`，只说明目录拾取或外部互相关测量来源，不自动推断测量精度。共享拾取的 CT 相关；CT 和产生它的绝对拾取也相关，不能按行数假设独立。

`sigma_s>0` 是测量标准差或明确声明的工作假设，不由质量码、拾取概率或相关系数自动换算。经验行因子与 sigma 分开，详见原理文档。绝对定位要求每条到时有 `quality_code`，或在配置里给出 `absolute_weighting.default_quality`（0–9）；省略该列时必须显式指定默认质量，不能自动视为质量0，也不从 `sigma_s` 换算。

与绝对到时满足 `dt_s = arrival_i − arrival_j`（同一台站、同一震相，容差 1e-9 s，且两侧各只有一条匹配）的目录 CT，测量误差就是这两条到时的差。误差传播使用这个线性关系。定位仍按各自方程行权，不删除这些 CT。CC 以及数值对不上的 CT 保持各自的 `sigma_s`。

## 原生 CSV

按列名读取，允许调整列顺序；拒绝重复表头和未声明列。支持标准双引号：字段中双引号写 `""`，含逗号或换行的字段置于引号内。未加引号文本去首尾空白，引号内文本保留。数值须有限，必需字段不能空。缺失测量应省略相应可选字段，不写零冒充缺失。

| 表 | 必需列 | 可选列 |
| --- | --- | --- |
| 台站 | `station_id,x_km,y_km,z_km` | 无 |
| 初始事件 | `event_id,x_km,y_km,z_km,origin_s` | 无 |
| 绝对拾取 | `event_id,station_id,phase,arrival_s,sigma_s` | `quality_code,observation_id` |
| 到时差 | `event_i,event_j,station_id,phase,dt_s,sigma_s,source` | `original_quality` |

事件/台站身份必须存在。同一事件对、台站、相位和来源的差分不重复或反向再写一份；CT 与 CC 仍分别保留。有效重复读数需要独立身份和相应误差假设，不能无意重复计权。

结果 CSV 与输入初值表不同，使用 `read_location_results` 读取保存的定位目录，不把结果的附加字段任意喂给 `read_events`。

## 原生内存输入与配置准备

`prepare_case(path)` 按配置文件目录解析相对路径；字典入口 `prepare_case(config;base_directory=...,inputs=(;))` 按明确的 base_directory 解析。返回数据按只读使用，科学输入或配置变更后重新准备。

`inputs` 可含 stations/events/picks/differentials 的任意组合，逐表替代文件：

- stations：字符串站 ID 到三元组 XYZ km 的字典。
- events：含 `event_id,source_km,origin_s` 的 NamedTuple 向量。
- picks/differentials：采用上述 CSV 物理字段名的 NamedTuple 向量。

全部必要输入已提供时可省略对应文件。向量原序及显式身份保留；不猜 DataFrame 列的单位或物理意义。`check_case` 和 `effective_config` 接受相同入口，只检查并返回说明/生效配置，不执行定位或清理输出。准备成功不证明射线可达、收敛或真实准确度。

`run_case(...;write_results=false)` 执行相同科学计算并返回内存结果，不创建、删除或写出结果文件。`input_sources` 记录实际文件或内存来源，`calculation` 保存有效设置；配置模板中的注释不是已经生效的科学选择。

## 模型与相位

常速分层的层顶严格递增，最后一层为半空间，允许低速层。连续梯度参数的速度位于声明的顶面；分段梯度的 depth 是速度节点，不是常速层顶。具体适用条件见[原理](MaoyeLoc原理.md)。

独立 P/S 模型中，P 用 p_model 的 P 参数，S 用 s_model 的 S 参数，各自正演，不缩放 S 速度或 S 延迟。`PhaseModels` 的另一种显式定义为：

```text
F_S = a*T_P + b + a*d_P
grad(F_S) = a*grad(T_P)
```

a>0 无量纲，b 为 s 的经验截距，不是发震时刻或台站延迟，也不表示唯一真实 S 速度结构。此模式只提供 P 延迟，不能同时提供独立 S 延迟。未显式选择时不自动使用此关系。

按台站模型使用明确的模型 ID、站 ID 和 P/S 延迟。区域模型按当前源位置混合完整预测：

```text
F = sum(w_m*F_m)
grad(F) = sum(w_m*grad(F_m) + F_m*grad(w_m))
```

固定延迟或相位截距在区域混合后也通过第二项贡献水平偏导。区域模型是经验加权的一维预测，不是唯一三维射线路径。

## 原生走时表

`TravelTimeTable(distance_km,depth_km,time_s;title="")` 存单相 T(r,z)。distance 是水平距离 km，depth 是源相对于固定接收面的深度 km；`time_s` 的**行为深度、列为距离**。使用 Float64 秒，不用整数编码、约化慢度或隐含缩放。各轴从0起、严格递增、至少3点，可非均匀；网格与矩阵一致。超过任一轴最大节点时按该轴最后两节点线性外推，并报告 extrapolated；负距离/深度拒绝。

`TravelTimeTableModel` 明确 `station_plane_km`；所有接收点 z 都必须等于该平面，查表深度为 `source_z-station_plane_km`。表不包含任意站高程修正，不能取代源、站深度均变化的射线模型。P、S 可用独立表，或显式选择从 P 表按比值缩放 S；二者不同时使用。生成表时固定接收面，改变输出网格不得改变介质或物理接收面。

## 计算深度与报告深度

`z_km` 始终是共同计算坐标的源 z。可选 depth_report/depth_reporting 只追加模型基准面或已声明大地水准面下的报告深度，不移动源台、模型、走时、残差和约束。程序不计算大地水准面起伏，也不自动把椭球高变成海拔。

设所选台站高程均值为 H，模型数值零面为 z0：

```text
coordinate_datum=model: model_depth=z_calc-z0; geoid_depth=model_depth-H
coordinate_datum=geoid: geoid_depth=z_calc; model_depth=geoid_depth+H
```

`model_datum=geoid` 使用 H=0；`model_datum=nearest5` 使用高程已知、按水平距离选取的至多五个不同站点。默认 `station_selection=nearest5`；显式 `nearby5` 优先选 ≤100 km 且高程 ≥−0.120 km 的至多五站，无合格近站时回退至最近高程已知站，不足五站取实际均值。均未知则 H 未知，不能补零。不同组件归同一站点需明确 station_site_ids，不按相同坐标猜测。

仅 coordinate_datum=geoid 且未提供 station_elevations_km 时，允许用 −station_z 作为高程；显式表缺项保持未知。报告 model_zero_km 的默认由实际模型定义决定，应在 effective_config 与输出中核实；需要特定零面时显式填写。区域模式的报告规则按主导父区域确定。误差仍对应计算坐标，不含基准面高程、选站切换或主导区域切换的不确定性；质量分类若采用报告深度，其分类也可能随报告规则改变。

## 震级改正、汇总权与增益开关

震级的静态 coda_correction_mag、amplitude_correction_mag 和站改正历史 value 均是直接相加的 mag 增量，不编码事件退出或增益开关。coda_weight/amplitude_weight 为独立的0:10站汇总权（默认10），coda_gain_enabled 为独立布尔开关（默认true）；历史 event_weight、尾波历史 gain_enabled 可显式覆盖，省略时分别继承通道值。匹配历史不自动重置权；权0保留站计算但不进入事件汇总。过期改正保持未知且汇总权0，未列通道由显式 use_unlisted_* 决定。物理改正、汇总权和增益开关分别提供，不使用 +5/+10 等数值暗码。

## 输出、误差与缺失值

默认输出事件位置、起时、状态、已请求的误差及其定义。配置了地理参考时另存经纬度和UTC起时。`[output] diagnostics=true` 增加残差、权重、选择、几何和迭代文件。残差为观测减预测，附带 used/unused、原因和实际权。事件状态、目录资格、分量、参考条件及误差状态分别保存。`completed` 表示流程结束，不意味着所有事件成功或误差均可估。

DD 最终残差和逐观测诊断的 `input_row` 是原始输入列表的一基记录序号，差分与联合绝对拾取分别计数，不含 CSV 表头。ABS→DD 排除失败事件后仍保留这个序号；逐行权按排除前的资料填写并同步筛选。未进入 DD 的原记录保留身份、序号及退出原因，实际行因子为0，未计算预测/残差留空。

CSV 中未计算、不可估或缺失量留空，结合 status/reason 阅读；真实 0 和有效负值保持。TOML 中没有 null：普通结果元数据把 nothing 写成字符串 "not_available"，报告元数据把 nothing 和 missing 都写成该字符串；不能据此恢复二者区别或假设所有普通结果均能序列化 missing。某些不存在的可选字段（例如未提供的观测 ID）会省略，应连同具体文件约定阅读。原生 physical state 2 用专用类型标记分别保存 nothing/missing，并保留数组形状与Symbol；它与普通报告的表示规则不同。未知方向、固定参考及未计算误差不得用假零表示。

条件协方差和条件标准差固定模型、站、相位分支、权及约束；完整算法传播固定初始目录和计算设置。它们均不自动包含速度模型、初值、参考事件真实误差或绝对准确度。置信椭球与逐轴边际区间按不同维数解释。

`[execution] tasks` 并发独立事件/差分连通分量；`replay_tasks` 并发同一误差方向的扰动重算，两个层级不可同时大于1。诊断输出开启后，detail=core 省略逐次历史和谱文件，full导出完整诊断。输出开关控制附加分析和文件导出，求解及所请求误差使用同一计算路径。阶段耗时含实际首次编译成本。




## 经验行因子

绝对定位的方程权是经验行因子，不是 `1/sigma_s`。`sigma_s` 仍是到时的测量标准差，必须为正，但不进入定位方程权。`quality_code` 为 0–9 的整数；缺这一列不是质量 0，也不能由 `sigma_s` 换算，须显式给出或设置 `default_quality`。`used` 与实际求解状态另行保存。`weighted_sum_squares` 是加权残差平方和，用来核对残差，不另作第二种目标。

## 原生射线诊断与邻居配对

trace_ray的source_depth_km是共同z而非相对站深度，launch_angle_deg从向上竖直计，P/S分别选真实速度数组。ray_geometric_density是sin(phi)/(r|dr/dphi|)，phi求导使用弧度、结果km⁻²；不等于观测波幅或完整弹性几何扩散。未定义时返回nothing，不能填0。

pair_neighbors使用Julia读数的显式非负pair_quality与important布尔项，前者是无量纲配对质量、后者是保留优先性；均不作为sigma。输出完整到时差与独立拾取sigma；重要性只作用选择，不改变物理观测。它是pair_catalog之外的可选邻居/强链/预算选择方法，详情见手册。
