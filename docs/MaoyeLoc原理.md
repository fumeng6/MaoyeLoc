# MaoyeLoc 数学物理原理

MaoyeLoc 从给定速度结构和台站位置计算 P/S 首波到时，用绝对到时与事件间到时差估计震源位置、发震时刻，并根据外部振幅或尾波测量计算震级。本文说明方程、物理假设、数值方法和误差含义。输入单位、身份与文件定义见[数据约定](数据约定.md)，命令和配置见[用户手册](用户手册.md)。

绝对定位采用 Geiger 线性化与加权最小二乘思想；双差方程来自 Waldhauser & Ellsworth (2000)。HYPOINVERSE 和 HypoDD 的手册用于说明方法与经验关系的来源，不定义本程序的默认值或输入格式。本文分别说明原理、显式数值选择及误差含义，科学来源及相关章节列于文末。

## 研究问题与假设

在给定台站位置、P/S 速度结构和相位识别下，以到时估计局地事件位置与发震时刻；利用事件间同站同相到时差减小公共路径误差的影响。模型描述标量 P/S 几何首波，不计算完整弹性波场、反射/转换振幅、散射、衰减波形或震源机制。到时差能减小部分共同误差，但不能保证未知结构误差完全消失。

直接射线模型为水平一维介质。各相位分别遵守 Fermat 原理和 Snell 定律。允许的低速结构以相应模型的明确条件为限，不把有限候选搜索当作任意三维模型。按台站选择及按区域混合是显式预测规则，其空间含义不同于真实三维射线。

单位 km、km/s、s，坐标东/北/下，详见[数据约定](数据约定.md)。

## 走时与源偏导

均匀速度 v 下：

```text
T = norm(source-station)/v
grad_source(T) = (source-station)/(v*norm(source-station))
```

重合两端的几何走时为零，但源梯度不唯一，常规 travel_time 拒绝该梯度；固定参考等仅需正演时间的路径可使用明确的零几何时间，仍保留适用的相位截距或站延迟。

水平常速层中，水平慢度 p 沿路径不变，令穿越厚度为 h_j：

```text
q_j = sqrt(1/v_j^2-p^2)
X(p) = sum(h_j*p/q_j)
T(p) = p*X + sum(h_j*q_j)
```

直达候选解 X(p)=水平源台距；临界折射候选取 p=1/v_refractor，非零射线腿速度须小于折射层速度，水平距离须足够。所有允许候选比较最早到时。每个端点用其实际深度和相位速度，不以事件对中心慢度替代两个源的慢度。

直达射线以所穿越层中最大速度 v_max 对应的角度变量 u=tan(theta_max) 求解水平距离。该变量使 p=u/(v_max*sqrt(1+u²)) 始终处于允许范围。水平距离对 u 的导数为正；Newton 试步限制在包围根的区间内，越界时二分，停止精度按水平距离的 Float64 舍入尺度判断。求得 p 后仍按上述 Snell 走时和源端慢度计算，不改变首波候选或速度模型。

对光滑、各向同性的一条首波射线，Fermat 原理给出源端关系 $\nabla_s T=-\mathbf{s}_s$，其中 $\mathbf{s}_s$ 沿源到台站的传播方向，模为源端相位速度 v_src 的倒数。若 A 是**从源指向台站**、自北顺时针的方位角，theta 从向下竖直方向计，则

$$\partial_xT=-\sin\theta\sin A/v_{src},\quad
  \partial_yT=-\sin\theta\cos A/v_{src},\quad
  \partial_zT=-\cos\theta/v_{src}.$$

这与均匀介质公式一致：源朝台站移动，走时应减小。若改用台站指向源的方位角，水平符号随定义改变；不能保持原方位定义而漏写负号。

光滑首波的水平源偏导为 p 乘从台站指向震源的水平单位向量，垂向为带初始传播方向符号的源端垂直慢度。真实速度跳变或首波等时分支具有不同源慢度时，不存在唯一导数，返回 nothing；求解器记录的局部差分只是非光滑近似。名义界面两侧相位速度相等时不应制造虚假的不连续。

双差计算中，若震源恰好位于常速分层模型的速度跳变界面，垂向采用浅侧单侧差分近似，水平分量沿用局部中心差分。浅侧步长限制在相邻层厚的一半以内，震源坐标保持输入或当前迭代值。这是对非光滑线性化的确定选择，首波正演仍保留无唯一源偏导的状态，求解器记录局部差分次数。其他无唯一源偏导的情形沿用相应模型的局部差分。

### 梯度模型范围

| 模型 | 速度定义与范围 |
| --- | --- |
| LinearGradientModel | v(z)=v_at_top+g*(z−top)；P/S 顶速正且 P>S，gp≥gs≥0，允许零梯度 |
| FiniteGradientModel | 有限梯度层，下接常速半空间；各相梯度非负，半空间速度不低于层底；顶、底、半空间分别 P>S，不要求 gp≥gs |
| PiecewiseGradientModel | 共同节点间连续线性速度，最深节点下常速；节点深度严格递增且 P>S>0；每相最多一组连续下降段，末速度为该相全局最大值 |

分段模型可表达条件允许的低速带，但不表达真正的速度跃变；常速分层模型另行表达跳变。模型顶必须覆盖源和站，不用静默延拓代替物理声明。

连续正梯度半空间有可独立计算的闭式。令两端相位速度为 v_s、v_r，三维直线间距为 R，梯度为 g>0，则圆弧首波：

```text
a = g*R/(2*sqrt(v_s*v_r))
T = 2*asinh(a)/g
D = sqrt(v_s*v_r+(g*R/2)^2)
dT/dx_s = ((x_s-x_r)/R)/D
dT/dy_s = ((y_s-y_r)/R)/D
dT/dz_s = ((z_s-z_r)/R-g*R/(2*v_s))/D
```

g→0 时回到 R/v 及均匀介质源偏导。实现用 `asinh(a)/a` 的极限表达，避免很小梯度下相消。圆弧向较深高速侧偏离弦，两端固定；不能用无限圆的转向点判断实际有限弧必然越过层底。

有限/分段梯度的每段计算来自同一 Snell 积分。对一条向下的单调腿，v(z)=v_a+g*(z−z_a)，c=sqrt(1−p²v²)：

```text
X_leg = integral(p*v/sqrt(1-p^2*v^2) dz)
T_leg = integral(1/(v*sqrt(1-p^2*v^2)) dz)
g!=0, p!=0: X_leg = (c_a-c_b)/(g*p)
g!=0: T_leg = log((v_b/(1+c_b))/(v_a/(1+c_a)))/g
p=0: T_leg = log(v_b/v_a)/g
g=0: X_leg = h*p/sqrt(1/v^2-p^2), T_leg = h/(v*sqrt(1-p^2*v^2))
```

上行腿按其实际穿越范围取正路径积分；转向处 p*v=1。源台间各腿相加并解总水平距，界面候选还须满足临界距离及实际弧范围。实际实现对近零梯度、近水平和近临界条件使用有理化、log1p及稳定参数化；这些代数形式不改变上述积分。它们提供独立参考计算的直接出发点，而非必须调用待查函数。具体路径与公式实现分别在 [gradient.jl](../src/gradient.jl)、[finite_gradient.jl](../src/finite_gradient.jl) 和 [piecewise_gradient.jl](../src/piecewise_gradient.jl)。

### 原生走时表

表存固定接收面上的单相 T(r,z)，Float64 秒。插值和相应偏导是表面的数值近似，精度受原始正演、网格、插值和分支切换影响。高阶插值不能消除低分辨率表的物理误差；应在目标源台范围与直接解析/射线结果比较。轴最大值外按末两点线性外推并报告 extrapolated，负距离/深度拒绝；外推精度须另行核实。固定接收面外的站点不能通过钳高程处理。表文件保存轴、矩阵顺序及完整浮点精度。

各轴选最近内部节点及左右共三点，构造二次 Lagrange 基 L_i(r)、M_j(z)，并以张量积 `T=sum(L_i*M_j*T[j,i])` 插值。偏导对同一多项式求导；不是另插一张慢度表。每轴越过最大节点时换用最后两点的线性基。模板切换若两侧值或一阶偏导不同，记录非光滑而不声称唯一源梯度。

若调用者声明每节点绝对误差不超过 ε，则时间的节点误差传播上界为 `ε*sum(abs(L_i*M_j))`，偏导相应使用导数基系数；这仅约束节点扰动，不包括插值截断、外推或速度模型误差。node_error_s=0表示未声明节点误差，不能解读为结果无误差。表插值公式和接收面映射分别见 [travel_time_tables.jl](../src/travel_time_tables.jl) 及 [travel_time_generation.jl](../src/travel_time_generation.jl)。

### 相位、台站和区域组合

独立 S 模型按自己的 S 参数计算，不再次乘 P→S 比例。显式仿射关系 F_S=a*T_P+b+a*d_P 则是经验 S 预测，a>0、b 为秒，并非唯一物理速度层。

台站延迟为已知固定量，正号使预测变晚；相位和模型 ID 精确匹配。区域权重由当前震源位置决定，完整预测与偏导为：

```text
F = sum(w_m(x)*F_m(x))
grad(F) = sum(w_m*grad(F_m)+F_m*grad(w_m))
```

相位截距和固定站延迟也参与后项。各区域先应用自身相位和台站模型，再混合；起时只在最终加一次。该经验混合不等于穿过区域边界的一条三维射线。

## 绝对到时定位

### 到时方程与线性化

事件 i 在台站 k、相位 p 的到时写成

$$a_{ikp}=O_i+F_{kp}(\mathbf{x}_i)+\epsilon_{ikp}.$$

O 与 a 都是相对于同一 UTC 参考的秒；F 是包含所选走时、相位截距及已知台站延迟的完整相位预测。对四参数 $\mathbf m=(x,y,z,O)$，预测的 Jacobian 行为

$$J_{ikp}=(\partial_x F,\partial_y F,\partial_z F,1).$$

残差 r=观测−预测，更新 $\mathbf m\leftarrow\mathbf m+\delta$，所以线性方程为 $J\delta\simeq r$，不是对残差取导后仍写同一正号。几何走时 T 不含起时，$\partial T/\partial O=0$；完整到时对起时的导数才是 1。

### 测量标准差与方程行因子

记完整预测 f=O+F，观测为 a，残差 r=a−f，J=df/dm，m=(x,y,z,O)。测量标准差为 sigma，R=diag(1/sigma)：

```text
min_delta ||R*(r-J*delta)||^2
```

当自由参数满秩且行因子固定时，线性步的形式为

$$\delta=(J^T R^T R J)^{-1}J^T R^T Rr.$$

实际方程行因子是经验因子 q，不是 1/sigma。程序用 SVD 求解该加权步，避免显式形成逆矩阵。到时对发震时刻是线性的，但当前路径把位置和发震时刻放在同一次改正里，不单独消元起时。

经验行因子 q 的目标为 sum((q*r)^2)，不能把 q 当成方差或已经平方的权。动态距离/残差重加权改变当前目标及资料选择，由所选方法和实际生效参数明确记录；当前高层默认经验预设包含这些规则。质量码、相关系数和观测标准差无普遍一一对应关系。经验加权的每条到时必须带 quality_code，或由 default_quality 显式给出 0–9；缺省列不是质量 0，也不由 sigma_s 分箱。

绝对定位只有这一条路径：经验行因子，以及位置和发震时刻一起进入的 SVD 改正。它不先把起时从空间里消元。奇异值阈值、奇异值平移、步长控制和停止规则是这条路径上的控制，不用小的阻尼后步长冒充未阻尼步已收敛。测量标准差最小二乘、Huber 损失和多起点搜索不是本程序的定位方法。

这些定位均为非线性问题的局部迭代；首波分支切换和单侧台网可能产生多个局部极小。收敛状态表示相应局部停止判据满足，不保证全局最小或最接近真实震源。初值、模型与台网几何需结合研究问题选择；小残差不能单独证明真实位置准确。

经验绝对定位行因子由质量、台站、相位以及显式距离/残差渐减因子相乘。正行因子归一到均值 1；这种共同归一在普通未正则化最小二乘中不改变最优步，但会影响固定数值奇异值阈值和工作噪声尺度的解释。距离/残差的余弦渐减为内阈值以下 1、外阈值以上 0，中间 $[1+\cos(\pi(u-u_1)/(u_2-u_1))]/2$。它是经验迭代规则。

经验流程参考 HYPOINVERSE 的逐次线性化、经验行因子、SVD 谱更新及相关步长和停止规则。每轮确定经验权后，本程序在该轮固定权的目标下检查候选步，必要时缩短步长；下一轮重新加权导致 RMS 增大时，再按 rback_s 和 bacfac 回退。走时及偏导使用所选模型，深度边界采用共同垂直基准，第二近台站按物理台站身份统计，浮点与文件输出保留完整精度。固定权下的候选步检查不把动态经验加权改称一个全程固定的最小二乘目标。

粗差靠经验残差权降低方程因子，不另设 Huber 损失。初值只有目录给出的一个，不做多起点搜索。

## 双差重定位

### 物理条件与观测定义

若两事件间距远小于共同台站距离及速度非均匀性的特征尺度，两条射线在源区外较接近，未建模走时误差的共同部分在作差后减小。源区不共同路径的误差仍然存在，位置偏导只描述**给定模型下**的到时变化，不能自动吸收未知速度误差。此条件决定双差减小结构误差的有效程度；使用两事件各自偏导并不能取消近邻要求。

同站同相差分为 $d_{ijkp}=a_{ikp}-a_{jkp}$，预测为 $O_i-O_j+F_{ikp}-F_{jkp}$。目录 CT 从完整拾取到时作差；CC 是外部波形测量并已转换到同一参考下的完整到时差，原始 lag 不能不经参考转换直接输入。固定同站延迟只有在两事件适用完全相同的延迟时才精确相消；区域模型混合导致的源位置相关延迟未必相消。

互相关测得的是所选波形窗的相对时移。有限震源下，它对应的有效辐射位置可能与初动成核位置不同；小地震可近似一致，但不能把任何 CC 窗都无条件解释为成核点到时。Waldhauser & Ellsworth (2000) 的相关讨论见其 pp.1365–1366。

### 线性方程与连通性

双差预测和行方程为：

```text
dt_pred = O_i-O_j+F_i-F_j
J_row = [grad(F_i),+1,-grad(F_j),-1]
r = dt_observed-dt_pred
```

每行至多涉及两事件的八个参数分量；部分空间偏导可以恰好为零，因此不是“恰有八个非零元”。事件对形成连通图是信息传播的必要组织条件，连通本身不保证空间方向可辨识；还需足够的台站/相位几何和矩阵秩。配对的最少观测数是选择规则，不是独立信息数或八个参数自动可解的证明。obscc 与 obsct 之和为 0 时，不把所有有观测的事件收成一个基准。筛选后仍保留的差分按连通分量分别求解；分量不自动固定参考事件。正阈值仍由强链确定群，群内再读入弱链。秩亏分量的状态是 rank_deficient，该坐标不是已收敛的可用解。

纯双差的共同起时平移是精确零空间；共同空间平移对有限距离台站一般不是。对共同空间增量 h，一行的变化为 $(\nabla F_i-\nabla F_j)\cdot h$；仅在相同慢度近似或特殊几何下消失。真实零空间还取决于几何、资料及连接，不能固定宣称四维。

### 显式经验双差行因子

`relative_weights.jl` 的当前阶段行因子为 $q=Q\,q_{class}\,f_d\,f_r$，与 `sigma_s` 分开。分类为 CC-P、CC-S、CT-P、CT-S；外部质量 Q 不自动解释为相干系数或误差倒数。距离因子为 $f_d=[1-(s/c_d)^a]^a$（s<c_d），CC 取 a=5，CT 取 a=3；超出截止距离取 0，显式 -9 关闭此因子。

残差截止 c_r 在 0<WR<1 时为给定秒数，WR>=1 时为 WR×MAD/0.67449，MAD 分别从 CC 和 CT 残差计算。渐减为 $f_r=[1-(|r|/c_r)^3]^3$（|r|<c_r），超出取 0；零 MAD 时保留零残差、排除非零残差。剩余行因子低于 `min_weight` 时退出，默认阈值 1e-5。Waldhauser & Ellsworth (2000) 式(15)展示的是另一指数的 biweight 形式，使用时须区分本文给出的实际权函数。

这些经验阶段会改变有效观测，须保存退出原因和实际行因子。行因子不是测量标准差的倒数：两类资料的标准差相差 10 倍，并不使方程行因子相差 10 倍。分阶段更换 CT/CC 因子还包含解结构的经验选择，并非唯一的测量噪声标定。

### 参考条件、列缩放与阻尼

相对定位只有这一条路径，借鉴 HypoDD 的做法，而不是固定参考事件的未阻尼最小二乘：

| 内容 | 实际含义 |
| --- | --- |
| 行因子 | 分阶段的类别、距离和残差因子。`sigma_s` 保留为测量记录，不作为方程权 |
| 求解 | 列 RMS 缩放后的阻尼改正。小系统用该问题的密集 SVD，大系统用 LSQR |
| 绝对位置 | 不自动钉住某个事件。阻尼把改正拉向零，使事件群留在目录初值附近 |
| 联合绝对到时 | 可同时使用绝对拾取与差分；绝对行的默认因子为 1，不是把双差变成绝对定位 |

显式 `reference_event_ids` 可以额外钉住所列事件。这不是默认基准，也不用来代替阻尼。

默认阶段为三次、各 4 次成功更新。第一次 P 和 S 都是 1，距离和残差因子关闭，阻尼 5。第二次目录 S 因子为 0.6，互相关 S 仍为 1，残差因子 WR=6，CT 距离截止 10 km，CC 距离因子关闭，阻尼 5。第三次 CC 与 CT 的 S 因子为 0.6，两类距离截止 8 km，残差因子仍为 6，阻尼 5。未给先验质量时因子为 1，不由 `sigma_s` 换算。这些数值是本程序这条路径的默认，不是某一份 hypoDD 控制文件的逐项抄录。配置了 `relative.damp` 时，各阶段阻尼改用该值；配置了 `relative.weighting.stages` 时，用该表替换上述默认，省略的类别因子按 1 而不是按 0.6。

对 damped 路径，N 仅由数据列 RMS 给出：

```text
min_delta ||RJ*delta-Rr||² + damp²*||N*delta||²
```

damp=0 选择缩放空间的最小范数解。全零数据列不能建立物理约束，零更新不代表参数已知。密集 SVD 与收敛充分的 LSQR 可解同一阻尼问题，LSQR 的迭代条件估计不能直接套用其他程序的条件数经验区间。

SVD 截断、列缩放和阻尼是三件不同的事。对 $B=U\Sigma V^T$，未阻尼保留方向的系数为 $1/s_j$；标准二范数阻尼的系数为 $s_j/(s_j^2+\lambda^2)$。绝对定位显式谱路径的 $1/(s_j+\eta)$ 是另一种谱滤波，不能称作同一 Tikhonov 或 Levenberg–Marquardt 公式。不同参数单位下的混合时空谱也有不同数值尺度，须按实际配置解释。

缩放 DD 路径逐步重算走时、Jacobian、行权和列尺度，更新完整 XYZ/O；固定阶段数结束记为 completed_schedule，不代表严格步收敛。非阶段路径用相应未阻尼步检查停止，LSQR 达迭代或条件限制且未满足残差要求时保留失败状态。这条路径采用完整可行步，不提供每步非线性目标单调下降保证，也不单独消元起时。

LSQR 使用双对角递推估计残差。当估计值满足给定停止阈值时，以矩阵乘法重新计算增广残差和法方程残差，并用给定容差判断收敛，默认相对容差为1e-6。首次迭代、每32次迭代、达到迭代或条件上限以及出现数值异常时也执行实算。接受的解通过实算残差判据，返回的残差与最终改正量对应。

大型双差方程按每行两个事件的四参数块保存系数和列号。矩阵乘法直接累加各事件对的贡献，列RMS从相同系数计算。固定参考事件对应的数据列为空，联合绝对到时行只包含一个事件的贡献。

计算准备时为事件、台站和同站同相射线建立内部整数索引，结果继续按输入身份关联。已接受试步的未加权残差可用于下一次相同位置、相同行序的重加权。类别及输入质量因子共享，当前距离、残差尺度和阶段行因子分别计算。事件、台站及分量的RMS按各组原行序累加平方残差。

深度边界、固定深度和显式越过某深度面即退出的规则不同。负深度本身不必错误；airquake_policy=exclude_repeat 只在显式选择时按指定面处理完整试步，拒绝后全群不更新并对剩余资料重做，不静默换参考或重置群中心。

## 不确定性及置信范围

### 最终点的局部条件传播

绝对定位的 `absolute_uncertainty` 对经验行因子返回未估计。`absolute_formal_uncertainty` 在返回点冻结保存的方程权，用工作噪声 \(q=\mathrm{RDERR}^2+\mathrm{ERCOF}\times\mathrm{RMS}^2\) 传播局部线性映射：

```text
Cov(delta_m) = K*C*K'
```

相对定位的解析 `relative_uncertainty` 对列缩放阻尼返回未估计，不计算参数协方差。需要把观测误差传过完整重定位时，用 `relative_algorithm_uncertainty`。

C 的行列顺序为全部输入差分，随后全部绝对拾取，保留原序。未另行给出 C、且未声明观测独立时，若目录 CT 与唯一一对绝对到时满足 dt = arrival_i − arrival_j（容差 1e-9 s），声明独立观测会报错。用户给出的 C 会先检查形状、对称性和半正定性。这些检查不改变已经求得的定位，也不为阻尼步填一份协方差。

此 Gauss–Newton 近似忽略残差乘二阶导数项，固定模型、台站、分支、权和约束。它适合小噪声/小残差或前向近似线性条件；不普遍等于有限残差非线性重拟合的精确导数。未知模型、参考、初值误差及算法偏差均未包含。固定参考或固定深度作为条件，其不确定性保持缺失，而不是已知真实值无误差。

绝对形式误差在返回点冻结实际行权并传播指定工作噪声；工作噪声尺度与残差信息的组合由配置明确。按残差/受控步规则正常停止的返回点可报告这一条件产品，但不因此变成严格步收敛或完整算法误差。自由边界活跃、秩亏、截断和非光滑等情形按实际实现返回不可估原因，不能把丢失方向的协方差填零。

对满秩、无正则化、同方差的加权行工作噪声，才可将协方差写成 $q\,V\,\mathrm{diag}(1/s_j^2)V^T$。已给绝对 sigma 时不自动再乘一次残差方差；相关误差则用实际 KCK^T。若另估一个共同噪声尺度，自由度还取决于实际秩、固定参数和正则化，不能无条件套用 M−4N。原 HypoDD 论文的加权残差方差式不能直接当作本程序通用公式，SVD 也不会自动赋予协方差物理真实性。

### 完整缩放重定位算法的观测误差传播

relative_algorithm_uncertainty 扰动观测并完整重算定位，固定原始初值、模型和实际选项，以局部导数传播观测误差。它描述列缩放阻尼重定位，不是最终一步逆矩阵的替代命名。

给定 C=L*L'，exact 对 L 的每个非零列传播；randomized 对 L*z 方向传播，z 为独立 Rademacher 符号。auto 在不超过128个非零方向时精确逐方向计算，否则随机估计。每方向在 ±h 和 ±h/2 重算，以 Richardson 值 (4D_h/2−D_h)/3 作为导数并分别核对位置 km、起时 s 的数值预算。

重算若改变资料选择、退出、秩、阶段、停止或射线分支，或发生非光滑/活跃裁边，报告不适用。随机协方差是 mean(q*q')，另报协方差元素的 Monte Carlo 标准误差、对角相对误差和样本两半差异；这些是随机抽样诊断，不是数值导数误差或真实覆盖率保证。该方法不是 bootstrap/jackknife，不估计模型、初值/参考真值误差或有限迭代偏差。

### 标准差与置信区域

协方差对角线平方根是同时估计自由参数的边际标准差，不是其他未知量固定后的标准差。逐轴正态置信半宽与联合空间置信椭球不同。满秩空间 k 维高斯椭球满足

$$ (\mathbf x-\hat{\mathbf x})^T C_x^{-1}(\mathbf x-\hat{\mathbf x})\leq\chi^2_{k,p}. $$

其主半轴为 $\sqrt{\chi^2_{k,p}}\sqrt{\lambda_j(C_x)}$。三维 95% 比例为 2.79548348；一倍主标准差椭球概率约 19.87%，比例 2.4 的三维概率约 87.61%。Klein 手册 pp.128–129 的“32% / 2.4 为 95%”不能作为三维高斯置信概率照搬。空间协方差取联合估计结果的空间子块，对起时作边际化；“其他参数固定”的条件方差不是同一量。固定深度则是另一明确条件下的二维椭圆。误差条、数值容差、输入量化及野外准确度须分别报告。

## 震级的物理输入和经验关系

震级使用外部振幅、周期或从 P 到时至尾波结束的持续时间 F−P。程序应用测量单位、峰值定义、仪器响应/增益、校准历史、站与组件改正及距离关系，得到站震级后选择并汇总。该过程不重新测量波形，不把定位 sigma 当震级权。

持续时间 D（秒）的每一选定分段关系为 `Md=A+B*log10(D)+C*D+E*z+F*R+G*gain+station+component+additional`；D 的折点及各系数由 md1/md2 配置明确。Mt 对 tau=T_P+D 使用常数、log10(tau)、其平方、线性tau、深度及增益/改正项。各项分别输出，源深度是计算 z，R 是水平震中距。

对于已按对应 Wood–Anderson 记录标定的振幅，基本关系为

$$M_L=\log_{10}\!\left(\frac{A_{pp,mm}}{2\,CAL}\right)-\log_{10}A_0+S+C.$$

A_pp,mm 为毫米峰峰值，除以 2 转为单边峰值；CAL 的定义须与当前仪器类型一致，S、C 是 mag 单位的站/分量改正。速度记录的 MX 另用源码所声明的电机常数与周期响应近似，不能把原始 counts 直接当作 WA 毫米。

振幅先按输入峰值和单位转换为毫米峰峰值，再应用选定仪器/周期与增益关系、距离项 `−log10(A0)` 以及站/组件项。距离关系的科学出处沿 Klein 手册及其对应1.40关系说明保存：Eaton、Bakun/Joyner、Richter近似、Nordquist、Richter离散表和CISN/Uhrhammer并不是可互换的同一标度。Eaton远支为 `2.55*log10(s)−2.21`；Bakun/Joyner为 `log10(s)+0.003*s+0.7`；Richter近似令 l=2log10(s)，近支 `−0.15+0.8*l`，远支 `−3.38+1.5*l`。Eaton还含适用的近震中距项。s=hypot(R,z)+0.01km，两个原表改用R；其他适用范围及响应近似见手册，不把实现范围等同于物理标定范围。

原生正CAL的尾波增益项为 `−log10(CAL/3.95)`；历史匹配为UTC小时半开区间，不依赖事件排序。数字系统F为μV/真实count，输入百count编码不改变该物理定义。原关系的CAL、响应表及距离表属于经验标度，源码中与手册有差异处保留明确说明；不靠重命名消除这些适用限制。具体系数、默认和分项出处见 [magnitude_calibration.jl](../src/magnitude_calibration.jl)、[coda_magnitudes.jl](../src/coda_magnitudes.jl)、[amplitude_magnitudes.jl](../src/amplitude_magnitudes.jl) 及 [magnitude_aggregation.jl](../src/magnitude_aggregation.jl) 的公式说明。

站改正的物理增量、是否参与事件汇总、是否施加尾波增益项分开输入：静态及分时段改正直接以mag相加，通道站权为0:10，coda_gain_enabled为布尔值；分时段记录可独立覆盖权及尾波开关，省略时继承通道值。过期和未列通道按明确规则处理，零事件权不抹掉站震级。

Md 使用持续时间，Mt 使用“模型 P 几何走时+持续时间”的 lapse time；Mt 不重复加入发震时刻、站延迟或经验相位偏移。ML/MX 使用所选振幅类型与距离关系，模型系数和仪器类型须适合实际台网，不能仅因公式存在就外推到任何地区。默认加权中位数最小化加权绝对偏差之和；HYPOINVERSE 的 MEDWT 中点插值及百分震级舍入是另一显式汇总规则（quantization="legacy_centimag"）。有效负震级保持。

普通 case 在绝对定位目录上计算震级；ABS→DD 的震级不自动按最终 DD 目录重算。若需后者，应显式以该目录调用 magnitude_preparation。

## 实际行因子与观测对应

经验行因子与定位残差表使用同一保存值。ABS→DD 显式排除失败事件时，差分、联合绝对拾取及其逐行权数组使用同一保留索引；内部求解和观测误差重算使用同一筛后顺序，最终残差及逐观测诊断恢复各自原始输入记录序号。退出记录保留身份及原因，不进入方程，预测和残差保持缺失；0行因子表示未参与，不表示其测量误差为0。填写顺序见[用户手册](用户手册.md#ct-配对与双差)。

## 科学核对和适用条件

独立核对应针对具体问题：均匀介质解析走时/梯度、Snell 条件、端点与界面、相位比例/独立 S、旋转/对称、差分反向符号、固定条件下的协方差或误差传播。程序自生成再反演主要核对流程，不是独立前向证据。对真实数据，速度结构和测量误差须另有依据。

误差产品按本文给出的冻结行权或完整算法传播定义计算，不包含自动残差方差重标定或 bootstrap/jackknife。模型误差、台站/相位错误以及参考事件真值误差需按具体研究另行评估；不能将观测误差的条件传播当作这些误差的总和。
